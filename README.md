# ARA Research Artifacts (`ara/README.md`)

This project implements real scalar $\phi^4$ theory renormalization and critical phenomena in accordance with the QFT Midterm assignment (`FeynCalc_Midterm_Project.pdf`) and the ARA workflow.

## Structure
- `ara/source/assignment-requirements.md`: Traceability ledger mapping detailed assignment requirements.
- `ara/logic/claims.md`: Physical and mathematical claims per subsection.
- `ara/logic/experiments.md`: Computational and analytical experiment records.
- `ara/src/environment.md`: Software environment details.
- `ara/trace/exploration_tree.yaml`: Workflow trace and exploration tree.
- `ara/anchor/equation-map.md`: Anchor mapping to lecture notes and workbook.
- `ara/evidence/`: Subsection evidence folders (`outputs/`, `figures/`, `tables/`).
